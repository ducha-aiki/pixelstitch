# pixelstitch Modernization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** pixelstitch installs and its click-annotation widget works on modern stacks (py3.12, matplotlib latest, numpy 2, notebook 7/JupyterLab/VS Code) and the old known-good stack (py3.9, matplotlib 3.4, numpy 1), with CI guarding both.

**Architecture:** Adopt contributor PR #3 (nbdev v2 migration) as the base — it merges into master with zero conflicts. Make the widget code version-adaptive instead of pinning old versions. Add headless interaction tests (synthesized matplotlib `MouseEvent`s) that run via `nbdev_test`, and a two-leg CI matrix (old pins / latest).

**Tech Stack:** nbdev v2 (notebooks are the source; `pixelstitch/` is generated by `nbdev_export` and must be committed), matplotlib, ipywidgets/ipympl, kornia, GitHub Actions.

## Global Constraints

- Runtime compat range: matplotlib >=3.4 through latest; numpy 1.x and 2.x; Python >=3.9.
- No upper version bounds in `settings.ini` requirements.
- Requirements line (exact): `matplotlib>=3.4 ipympl kornia_moons kornia>=0.5.10 numpy`
- `min_python = 3.9`, `version = 0.2.0` in `settings.ini`.
- All edits to library code go into the **notebooks** (`core.ipynb` etc.), never into `pixelstitch/*.py` directly; run `nbdev_export` after notebook edits.
- Preserve Dawars' commits/authorship from PR #3 (merge, don't squash).
- Local dev env: `.venv/` in repo root (gitignored). Activate with `source .venv/bin/activate` or call binaries as `.venv/bin/<tool>`.
- Outward-facing GitHub actions (closing PR #3, commenting on issues) require showing drafts to the user first.

```python
#|hide
# Headless interaction tests: synthesize matplotlib MouseEvents against the
# Agg backend so nbdev_test exercises the real click-handling logic in CI.
import os, shutil, tempfile
import numpy as np
import matplotlib.pyplot as plt
from matplotlib.backend_bases import MouseEvent, MouseButton

plt.switch_backend('agg')

_pair_name = sorted(p for p in os.listdir('sample_project') if not p.startswith('.'))[0]
_tmpdir = tempfile.mkdtemp()
shutil.copytree(os.path.join('sample_project', _pair_name), os.path.join(_tmpdir, _pair_name))
_d = os.path.join(_tmpdir, _pair_name)
_pairs = [(os.path.join(_d, '01.png'), os.path.join(_d, '02.png'), os.path.join(_d, 'corrs.txt'))]

_ca = CorrespondenceAnnotator(_pairs, save_on_next=False)
_ca.start(figsize=(12, 7))

def _click(ca, ax, xy, button):
    x, y = ax.transData.transform(xy)
    ca.process_user_click(MouseEvent('button_press_event', ca.figure.canvas, x, y, button=button))

_n1, _n2 = len(_ca.pair_state['pts1']), len(_ca.pair_state['pts2'])

_click(_ca, _ca.ax1, (50.0, 60.0), MouseButton.LEFT)
assert len(_ca.pair_state['pts1']) == _n1 + 1, 'left click on ax1 must add a point'
assert np.allclose(_ca.pair_state['pts1'][-1], (50.0, 60.0), atol=1.0)

_click(_ca, _ca.ax2, (55.0, 65.0), MouseButton.LEFT)
assert len(_ca.pair_state['pts2']) == _n2 + 1, 'left click on ax2 must add a point'

_ca.save_current_pts(None)
_saved = np.atleast_2d(np.loadtxt(_pairs[0][2]))
assert _saved.shape[1] == 4, 'saved corrs must be Nx4'

_click(_ca, _ca.ax1, (50.0, 60.0), MouseButton.RIGHT)
assert len(_ca.pair_state['pts1']) == _n1, 'right click near a point must remove it'

_ca.figure.canvas.draw()  # force a render to catch draw-time regressions
plt.close(_ca.figure)
print('interaction tests passed')
```

- [ ] **Step 1: Replace the toolbar-cursor guard**

In the `CorrespondenceAnnotator` class cell of `core.ipynb`, add this method (next to `process_user_click`):

```python
    def _clicks_allowed(self):
        # Toolbar may be absent on headless backends; toolbar.mode is '' when
        # no zoom/pan tool is active, on both matplotlib 3.4 and modern ipympl.
        toolbar = getattr(self.figure.canvas, 'toolbar', None)
        if toolbar is None:
            return True
        return getattr(toolbar, 'mode', '') == ''
```

and in `process_user_click` replace:

```python
        # Not adding points when zooming
        zoom_pan = ['Cursors.SELECT_REGION', 'Cursors.MOVE']
        pick = 'Cursors.POINTER'
        ptr_type = str(self.figure.canvas.toolbar.cursor)
        if ptr_type != pick:
            return
```

with:

```python
        # Not adding points when a zoom/pan tool is active
        if not self._clicks_allowed():
            return
```

- [ ] **Step 1: Write test.yaml**

Replace the full contents of `.github/workflows/test.yaml` with:

```yaml
name: CI
on: [workflow_dispatch, pull_request, push]

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        include:
          - name: oldest
            python-version: "3.9"
            pins: '"matplotlib~=3.4.3" "numpy<2"'
          - name: modern
            python-version: "3.12"
            pins: ''
    name: test (${{ matrix.name }})
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: ${{ matrix.python-version }}
      - name: Install
        run: |
          python -m pip install --upgrade pip
          pip install -e . nbdev jupyter ipympl ${{ matrix.pins }}
      - name: Notebooks clean and in sync with library
        run: |
          nbdev_export
          nbdev_clean
          git diff --exit-code
      - name: Run notebook tests
        env:
          MPLBACKEND: Agg
        run: nbdev_test
```
